# Furniture Sales Analytics

An end-to-end Sales Analytics project that demonstrates data cleaning, SQL analysis, and interactive dashboard development using Python, Google BigQuery, and Looker Studio.

---

# Project Overview

This project analyzes a furniture sales dataset containing 10,000 transactions to identify sales performance, customer purchasing patterns, regional performance, and product insights.

The project follows a complete analytics workflow, from data preparation to business dashboard visualization.

---

# Business Problem

Retail businesses often struggle to monitor sales performance efficiently due to scattered transaction data.

This project aims to answer several business questions:

- Which product categories generate the highest revenue?
- Which regions contribute the most sales?
- Which products are sold the most?
- How many orders are completed, cancelled, and refunded?
- How can business performance be monitored interactively?

- Furniture categories have different completion rates.
